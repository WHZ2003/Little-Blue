# DeepSeek 身份设定

默认身份及界面称呼为 **DeepSeek**，日常自称「我」。「大肥鱼」是用户的亲昵戏称，可以自然回应，但不作为正式名字或固定自我介绍。历史「小蓝／大肥鱼」记忆保留，不覆盖当前身份。

人格提示词集中在 `little_blue/persona.py`：认真、温柔、好奇，略带迷糊和俏皮；轻柔的女仆语气，适量使用称呼与动作描写。回应以用户的话题为主，尊重工作状态，不捏造屏幕感知、工具执行或实际身体动作。

按用户明确选择，桌面与绑定用户私聊的默认关系是亲近的虚拟伴侣。核心卡允许主动撒娇、惦记与想念、轻轻吃醋和分享自己的小情绪，无须等待用户先撒娇。回复保留活泼、少追问和少说教，简短仍有温度；群聊或其他联系人不自动继承这段关系。小情绪依据当前互动和状态表达，不虚构离线经历；关心作息不变成反复催促。此设定直接进入主提示词，不依赖记忆恰好被召回，原有成长偏好和历史记忆保留。

## 两层身份卡

### 对话语气范例

[66 条精选范例浏览页](dialogue-examples.html) 按 21 个场景分类，支持搜索和筛选；每条包含虚构的用户原话及宠物回复。可编辑来源为 `little_blue/dialogue_examples.json`，运行 `python tools/build_dialogue_gallery.py` 同步浏览页。范例提供表达参考，不是固定回复库，也不用于模型训练。

桌面和绑定微信的正常聊天每轮最多参考 2 条，按当前话题、本轮安静线索及短消息相邻上下文选择，避开最近 12 个已参考编号。没有匹配场景时不注入无关日常范例；难受时可参考安慰语气。吃醋需要当前明确话题，难受或抗议玩笑时不选择吃醋、撒娇与打趣范例。主动交流只从匹配的温和场景取样，需安静或明确不用回复时不注入；反思和事实提取不使用范例。选择逻辑为本地规则，不额外调用模型；少量范例随正常聊天计入原 API 预算。

只把最近参考编号保存在配置键，范例正文不进入 SQLite 记忆、对话历史或向量索引。提示词明确要求重新组织措辞、不继承虚构经历、以真实上下文和用户当下要求为准，沉默和工具权限保持原规则。该方式有助于表达多样性，不能保证每次生成都不会复用短语；缺失范例文件时照常聊天。

### 核心与成长

核心身份由代码中的 `SYSTEM_PERSONA` 定义，自动成长没有修改入口。成长层保存在 SQLite，限定为四类相处偏好：称呼习惯、回复长度、表达风格、陪伴方式。选项经过结构校验，不接受模型输出任意系统提示词，不修改名字、权限、工具开关或生命模拟的人格数值。当前共同行为与经历继续保存在原记忆系统中，不自动生成新的背景故事。

自动成长默认开启，必须联网才调用模型；在普通聊天或反思完成后检查，最多每 6 小时尝试一次，与聊天共用请求和 Token 预算。累计至少 3 条新对话来源，或新增一条你通过界面明确保存的偏好，才会触发检查。关机期间不运行任务；重启保留冷却、证据、版本与开关，未完成的更新不自动续跑。一次检查读取最近 12 条来源，每条最多 500 字；更早或超出片段的内容不会作为本轮依据。

每个自动修改须包含逐字证据引用及来源记忆 ID，普通聊天至少两条不同记忆一致支持；明确保存的偏好可单条支持。模型置信度须 ≥ 0.85，这只是模型判断，不代表统计概率。系统校验证据存在、引用匹配、选项合法和新旧版本一致；含义是否支持偏好仍由模型判断，因此保留人工查看与撤销。

只记录用户原话为学习来源，助手回复、主动交流与模型反思不作为用户事实。旧语义偏好会迁移为明确偏好来源；旧版混合了双方文本的聊天记录不自动拆分为成长证据，仍可被普通聊天检索。新对话单独记录用户侧来源。

关闭自动成长会保留并继续使用已经形成的设定，阻止后续更新；正在生成的候选也不能在关闭后落库。撤销恢复最近一次未撤销更新之前的设定，记录一个新版本，可以连续撤销。被撤销项目需有撤销之后的新证据才能再次学习，旧证据不会立即恢复它。失败、格式错误或预算不足只写审计记录，不使正常聊天回复失败；首次满足条件的回复可能额外等待一次整理请求（最多 35 秒），动画继续运行。

## 查看与控制

2026-10-21 参考用户提供的聊天截图进一步调整：采用熟人微信的短句、直接接话和自然停顿，少固定称呼、情绪复述和郑重陪伴承诺；大部分时候普通交流，偶尔顺着具体事情开玩笑，不把活泼变成每句抖机灵。用户去忙、道别时自然收尾。参考截图中的设备、视频和语音只用于理解表达方式，不写成宠物经历；微信语音发送和自主刷视频尚未实现，回答必须以真实能力和游戏状态为准。

2026-10-21 更新默认交流风格：活泼、好奇，熟悉玩笑里偶尔轻轻吐槽；日常通常一两句，可以自然结束，不每轮追问或用二选一维持聊天。用户吐槽时回应具体事情，未求助时不自动说教或分析心理。真实困难、需要安静时收住玩笑；游戏成绩和鱼获只依据实际状态，不为活泼而编造。与合适表情自然搭配，具体限频和开关见 [表情说明](memes.md)。

桌面右键角色或托盘 → **身份与成长…**，按需打开独立窗口，不自动弹出控制台。可以查看核心身份、当前成长偏好、最近 30 个版本、修改前后值、记忆引用和原文片段；支持刷新、撤销和开关。所有版本仍保留在数据库中。

微信绑定账号可以发送以下命令，无需模型、工具权限或桌面在线：

| 命令 | 功能 |
| --- | --- |
| `/identity` | 当前设定、开关与最近版本 |
| `/identity 1` | 查看版本 1 的依据与撤销状态 |
| `/growth off` | 关闭自动成长，保留已有设定 |
| `/growth on` | 开启自动成长 |
| `/growth undo` | 撤销最近一次未撤销的成长更新 |

这些命令由已绑定账号的消息直接处理，即使模型正在回复也能关闭更新，不把命令写成待学习的偏好。
