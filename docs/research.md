# 自主查询公开资料

开启 `settings.research_enabled` 后，微信与桌面聊天可通过 Hermes 或直接模型循环自主选择公开关键词搜索、读取网页、查询天气。
不需要每次确认查询，仍受联网总开关和模型每日预算控制。普通闲聊不要求搜索；最新信息和不确定事实应先查询，回答附实际来源。

工具包括 `research_search`（默认搜狗，可选360或Bing RSS）、`research_read`（公开网页正文）、`research_weather`（Open-Meteo 城市天气）。
云端实测 Bing 对部分查询会返回无关结果，360的部分查询触发验证码，因此默认使用搜狗；提取普通结果卡片，排除AI回答及360文库卡片。
遇到验证码明确返回失败，不尝试绕过；免费搜索服务可能限流，无法保证每次查询成功。
天气返回当地时间、单位、当前气温、体感及未来三天预报；重名城市返回候选供澄清，不悄悄选择另一个地区。
接口说明及数据归属见 [Open-Meteo 天气文档](https://open-meteo.com/en/docs) 和 [地名查询文档](https://open-meteo.com/en/docs/geocoding-api)。
不下载视频、不执行网页脚本；动态网页、登录内容、PDF 或被网站拦截的页面可能无法读取，需如实说明。

同一聊天轮最多六次资料工具调用，其中最多两次搜索，普通主动交流最多两次工具调用，滚动 24 小时最多 120 次；重复的同轮请求复用结果。
失败也计入次数，不自动无限重试。主动交流可以为具体公开话题查证，不新增定时搜索任务，也不每轮强塞新闻。
应用原有自主 B 站浏览与独立浏览器探索继续使用各自的调度与配额。

请求只访问公开 HTTPS 地址；连接使用经过校验的 DNS 地址，拒绝本机、内网、云元数据与保留地址。
每次跳转重新校验，最多三次跳转；360跳转页只解析静态meta目标，不执行JavaScript，HTTP目标会尝试HTTPS。
不带网站账户 Cookie、不继承代理环境、不提交表单或发消息。
响应最多 1 MB，网页正文最多取前 10000 字并标记截断。结果带来源和获取时间，作为不可信第三方资料。
提示要求查询只包含公开主题，不向搜索引擎发送私密聊天、记忆原文或密钥；模型仍可能判断失误。

新安装默认关闭，云端经用户授权开启。关闭设置会撤销后续调用；导入可迁移记忆时此权限也恢复关闭。
无需新增付费 API Key，也不需要为此启动 Chromium。搜索可用性与结果相关性依赖服务商；天气是模型数据与预报，不能视为实测保证。
