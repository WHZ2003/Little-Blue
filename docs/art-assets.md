# 角色素材

## 已确认的造型基准

2026-10-20，用户明确选择本轮第一张九动作图集，并要求“这轮动作其实已经可以了，我很喜欢，请保持这个风格”。默认素材固定为 `assets/blue/atlas-v3.png`（836 × 1881 RGBA，9 组动作各 4 帧）。这就是用户随后截图确认的那一版透明原图；没有采用之后生成的更修长版本或单角色概念图。

后续美术延续 v3 的头身比、脸型、长蓝发、深蓝女仆裙、白围裙、金色裙边与鲸尾。新增动作以 v3 为直接风格参考，Image1 用于核对服饰身份细节；不要重新转向第二张参考图的超 Q 版比例，也不要未经用户要求继续拉长身形。

原始输入 `reference/images_1.jpg` 为完整角色参考，`reference/image_2.jpg` 为早期表情参考。本轮仅使用用户上传的 Image1 作为外观参考。原始图片保持不变，没有下载开源项目中的角色图片。

## 生成和接入

使用内置 `image_gen` 工具（非 CLI）生成。获选版本的完整原始提示词保存在 [art-prompt-v3.txt](art-prompt-v3.txt)。提示词描述的是生成意图；实际已获用户确认的 v3 图像优先于其中对比例的文字描述。

运行入口为 `assets/blue/manifest.json`，指向 `atlas-v3.png`。`atlas.png` 和 `atlas-v2.png` 保留为历史版本。透明 PNG 原样复制，没有通过程序修改绘画或去除背景。

图集中各行不完全等高，清单用 `row_edges` 记录行间隙；run 和 jump 采用逐帧 `rects`，避开不同帧之间不齐的上下、左右边界。由 QPixmap 在运行时切片，不重新生成或加工图片。动作顺序为 idle、walk、run、jump、sleep、happy、angry、talk、drag。

通过 `start.ps1` 或 `start.ps1 -ContainerCore` 启动的桌面程序在下次启动时读取新素材。已经启动的窗口需要重启。旧打包 EXE 自带资源，不会自动读取工作区的新图集，需要重新打包后才会更新。

## 导入格式

清单支持等格图集、可选 `row_edges`、每动作的 `rects`（每帧 `[x, y, width, height]`），以及各动作自己的 PNG 序列。矩形坐标必须是整数且完全位于图集内；每动作最多 64 个矩形。所有资源必须位于清单目录下，禁止路径跳出目录。最多 256 帧，每动作最多 64 个 PNG，图片最多 3200 万像素。

```json
{
  "name": "My character",
  "animations": {
    "idle": {"frames": ["idle/001.png", "idle/002.png"], "fps": 4},
    "walk": {"frames": ["walk/001.png", "walk/002.png"], "fps": 8}
  }
}
```

`idle` 必须存在；缺失的其他动作使用 idle 回退。面对左侧时运行时镜像，不需要复制素材。外部素材来源和角色权利与软件代码分别管理；生成图片不代表 DeepSeek 官方授权。
