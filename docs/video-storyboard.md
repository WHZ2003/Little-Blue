# B 站与雀魂省流观察

已将 [dsh-video-storyboard](https://github.com/SAOS-3624/dsh-video-storyboard) 0.4.3
的纯计算核心集成进现有 Coopanion 插件。固定提交与 MIT 许可在
`integrations/storyboard/UPSTREAM.md`、`integrations/storyboard/vendor/`。

## 使用

- **B 站**：继续使用原来的 B 站视频入口、登录态与微信电脑观看任务。默认开启“省流分镜”，首次约 2 秒出图，之后默认每 20 秒至多一次（模型繁忙会更慢）。按采样画面变化分配格位，最多 9 格，整图不超过 640,000 像素。每格带编号，文本附时间范围、实际取帧时刻和有长度限制的字幕。弹幕最多节选 6 条。原有 `bilibili_video_look` 可按需看清细节。
- **雀魂客户端**：继续在“雀魂麻将 → 陪我玩”启动。默认开启“客户端省流画面”，只发最新完整牌面的单格图，整图不超过 640,000 像素，不裁掉手牌、不混入历史牌面。保持原来的 10 秒节奏（最短 8 秒），本地灰度比较跳过近似静止图，下半部手牌区域使用更敏感的阈值。面板显示已发送和去重数量。
- **雀魂网页版**：仍使用现有协议公开状态与本地建议；无需额外发图片，陪玩仍禁止代打。

在原配置页关闭 B 站“省流分镜”或雀魂“客户端省流画面”即可恢复原画面策略。
不修改人设、记忆、账号或操作权限。现有官方 DeepSeek 目的地限制、退出取消、25 秒图片过期与窗口限定继续生效。

### 观看面板

B 站“播放状态”现在直接提供“启用省流分镜”、5–120 秒的分镜间隔和“应用分镜设置”。面板显示服务端确认的实际间隔、已生成张数及最近格数，保留原授权、浏览器按钮和最近分镜预览。修改后点击应用，轮询不会覆盖未保存的值；关闭省流即恢复原观察间隔。

雀魂“陪我玩 → 陪玩节奏”直接提供“客户端省流画面”，与原观察间隔一起保存；网页版隐藏该选项。上方状态显示当前模式、已发送和去重数量。旧后台未支持该字段时不会写入未知配置。

两套界面均使用内容哈希更新资源路径，重启后刷新页面即可加载。实机 UI 已验证 B 站 20→30 秒保存、关闭后恢复 5 秒、重新开启并恢复 20 秒；雀魂关闭/开启切换原清晰度/省流状态。验证结束保持两项省流开启、雀魂 10 秒且停止陪玩，未启动视频或游戏。

## 范围与限制

这是直播采样适配，复用了上游 `planCellRanges`、`bestLayout` 和像素预算；没有安装另一套 DSH 宿主，也没有接入全片下载、离线 `video_probe/video_zoom/video_locate`、FFmpeg 扫描或 ASR。无需另配 cookies 或 API key。字幕来自现有播放器接口，没有字幕时会明确说明未转写声音。

测试中的 9 格图片由原默认 1920×1080 降为 1065×597（像素约少 69%）。默认持续观察间隔由 5 秒变为 20 秒；这不等于账单减少相同比例，实际 token 和费用取决于模型编码、字幕、回复及对话上下文。没有测量真实 API 账单。

省流会损失小字细节；雀魂细微牌面变化也可能被近似去重漏过，看不清时应关闭省流恢复原清晰度。没有完整牌局状态的截图不适合保证实时出牌建议。暂停、退出、换视频会使排队或在途的旧画面失效；同一截图只投递一次。

## 安装与验证

```powershell
.venv/Scripts/python.exe tools/patch_coopanion_video_watch.py --package .research/Coopanion/data/extensions/node_modules/cortico-world-bilibili-video
.venv/Scripts/python.exe tools/patch_coopanion_majsoul_strategy.py
./tools/test_coopanion_video.ps1 -BrowserSmoke
./tools/test_coopanion_majsoul_strategy.ps1
```

安装器备份被覆盖文件并原子写入，避免改到 pnpm 共享文件；重复安装不会重复插入补丁。应用代码须重启进程加载，环境提示可通过原应用“重载前缀”更新。请在停止播放、停止陪玩且没有正在进行的模型轮次时重启。

验证包括真实无界面浏览器的图片尺寸、坏图片拒绝、微信触发实际播放并投递分镜、标签页归属保护，以及雀魂模拟牌局的只读陪玩、停止取消、目的地检查、近似去重和过期恢复。当前机器未打开雀魂客户端，尚未验证真实牌面的识别效果或实际费用。

本次安装验收：B 站/同步/分镜 32 项测试与 3 项真实浏览器烟测通过；雀魂 47 项测试通过（其中一次 Edge 提前退出的启动失败已单独复测通过）。重复安装检查无变更。已通过应用正常重启并重载会话前缀，两个 World 均 active，雀魂运行实例报告 `dsh-0.4.3-live-v1`、`pixelBudget=640000`、`allowActions=false`。完整安装前备份位于 `backups/storyboard-install-20261028-211821/`。
