# 架构与阶段验收

新增可选 [Docker 核心模式](container-core.md)：`core.py` 运行独立生命时钟、Agent、SQLite 和审批状态；`service.py` 提供认证接口；`remote.py` 将 Qt 桌面端接到它。本页下文描述原有纯本地模式。两种模式共享 Life、Agent、ToolRuntime 与 Store，不共享数据库连接或 UI 时钟。

## 时钟与职责

`PetWindow` 的 Qt 精确定时器以目标 60 Hz 更新物理和动画；`Controller` 每 250 ms 推进生命状态。网络仅在独立线程内的 asyncio 事件循环执行，通过 Qt Signal 回到 UI。屏幕刷新不等待模型输出。

`Life` 不导入 Qt、HTTP 或 SQLite。Needs 随真实时间变化；Utility 选择目标；带状态的 Sequence 顺序执行 TimedAction 叶节点。每个目标有持续时间、冷却和随机权重，拖动/点击覆盖行为可恢复，低精力会优先进入休息。

情绪低通收敛到需求决定的 Valence/Arousal，避免每帧随机换情绪；Personality 独立持久化并参与效用和语言上下文。睡眠恢复精力，探索消耗好奇，活动降低无聊。长时间拖动引起不高兴。

## 认知和工具边界

`Agent` 处理显式对话、低频主动交流和反思。输入由固定人格、结构化状态、近期事件、检索经历和用户明确保存的偏好组成。工具/网页/文件返回值视为不可信数据，不改变系统权限。所有自然语言都按纯文本呈现。

LLM 只能从注册的函数 schema 中提出调用。ToolRuntime 验证模型、规范化路径、冻结参数、等待一次性审批，再检查权限是否仍开启。环境活动还有独立感知开关。默认不开启工具、感知或联网；截图只能由用户在 UI 手动触发，并写入审计记录。

网络请求 35 秒总超时，实际工具 25 秒，单次审批 120 秒，整个认知任务 240 秒。没有自动网络重试以免不透明地重复计费或副作用。用户取消会取消 asyncio 任务与待审批窗口，已经发生的操作不会回滚。工具日志只保存名称、结果类别和时间。

公开页面工具限制 HTTPS、禁止凭据和私有地址，Playwright 使用隔离环境、不继承浏览器登录态、禁用脚本和下载。它是有限公开页读取功能，不是任意网页操作器或对恶意网站的完整沙箱。

## 数据生命周期

- `kv`：Settings 和 Needs/Emotion 状态，15 秒及退出时保存。
- `memories` + `memory_fts`：经历、明确偏好和模型反思，保持类型区分。中文检索在 FTS 无命中时采用字面子串回退。
- `conversation`：带桌面／微信来源的用户和助手发言；最近 12 条用于认知上下文，最近 24 条用于小聊天窗，重启保留。
- `kv.current_activity`：用户明确自述的当前事项、依据、状态与跟进时间；不是可执行任务。跟进另受持久次数、勿扰和共用主动交流门控限制，参见 [日常陪伴](companionship.md)。
- `kv.phone`：2048 棋盘及纪录、鱼类收藏、水族箱养成、自主开关和游戏日记。纯离线 `Phone` 在核心生命时钟内选择活动和操作游戏；`phone_ui.py` 只显示状态、提交经认证及版本检查的人工操作，参见 [虚拟手机](virtual-phone.md)。
- Working Memory：有界事件队列；重启不恢复执行上下文。
- `tasks`：任务结果；启动时 pending/running/approval 一律变为 interrupted。
- `budget`：先预留后发送，跨重启保留每日预算。
- `reminders`：独立且用户已批准的本地定时提醒，交付后标记。
- `audit`：工具权限与执行结果，不包含文件正文、参数或 API Key。

SQLite WAL + 共享锁串行化主线程和认知线程写入。退出先取消后台任务，等待线程结束再保存和关闭数据库。
