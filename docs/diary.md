# 大肥鱼的日记

云端核心每天 23:00（America/New_York，自动处理夏令时）空闲时写当天日记。
重启错过时间时只考虑补写昨天，不一次补写许多天；没有可用经历就不编一篇。
日记默认自动开启，安静地保存，不自动通过微信发送。

微信指令：

- `写日记` 或 `/diary write`：现在写今天；有新增经历时更新同一天的一篇。
- `看看日记` 或 `/diary`：查看最新一篇。
- `日记 2026-10-22` 或 `/diary 2026-10-22`：按日期查看。
- `日记列表` 或 `/diary list`：最近 30 篇的日期。
- `开启日记` / `关闭日记`（也可 `/diary on` / `/diary off`）：控制自动写作。
- `/diary status`：查看开关、篇数和时区。

正文用她的第一人称写具体经历和主观感受。素材包括当天已确认的聊天、读过的 B 站字幕、
实际网页记录和虚拟手机活动。一天最多抽取 32 条聊天、4 条字幕和4条活动，长内容截断；
它不是全天所有消息的逐条归档。助手过去说过的话不当作事实证据。

生成走当前 DeepSeek / Hermes 配置，共用既有每日 API 预算，工具与额外私密记忆检索关闭。
自动生成每个日期最多尝试一次；手动重试间隔至少五分钟，相同素材直接复用已有日记。
生成失败或取消保留原文；新聊天会打断后台日记。关闭联网仍可查看旧日记。

日记正文、素材快照和来源编号保存在 `memory.sqlite3` 的 `diaries` 表，
随现有记忆备份和交接迁移；不写进用户事实表，也不把日记递归当作后续日记的素材。
受认证的 `/diary` 接口支持 status/list/read/write/on/off；write 返回任务编号，完成后 read 读取。
运行日记和素材属于私密数据，不提交到 Git。
