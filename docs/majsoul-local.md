# 本地雀魂浏览器与桥接

Coopanion 的 `cortico-world-majsoul@1.1.1` 原面板“打开游戏”只调用 `connectOverCDP`，不会启动 Edge。未先运行扩展另附的启动脚本时，配置端口没有监听，出现 `ECONNREFUSED`。普通浏览器里已打开雀魂也无法代替这个专用调试浏览器。

本地补丁将启动流程接入“打开游戏”和首次“附着桥接”：

- 使用当前 World 的 `browserPort`，默认 `29733`。
- 专用资料目录为 `<bot dataDir>/majsoul/edge-profile`，复用登录状态。
- 只连接属于这个资料目录的 Edge，调试端口只监听回环地址；端口被其他进程占用时明确报错。
- “打开游戏”先启动并等待调试接口，再安装桥接、加载游戏；已有连接时复用页面，并恢复最小化窗口、选中游戏页、显示到前台。开局后也可点击该按钮显示窗口，不刷新牌局。
- “附着桥接”保留当前页面；首次启动的空白页会打开雀魂。
- 界面分开显示浏览器连接与牌局连接。大厅或正常加载刷新显示“已就绪，等待开局”；实际进行中的牌局断线仍停止操作并报告原因。

安装后的代码位于 `.research/Coopanion/data/extensions/node_modules/cortico-world-majsoul`。可维护的启动器源码位于 `integrations/majsoul/`，应用补丁：

```powershell
.\.venv\Scripts\python.exe tools/patch_coopanion_majsoul.py
```

补丁检查版本和源代码结构，先备份至 `backups/majsoul-panel-*`，不修改人设、游戏策略、账号配置或自动操作权限。应用后正常重启本地 Coopanion 以加载模块。插件升级可能替换补丁；其他版本需要重新检查兼容性，不能直接覆盖。

验证：插件原有 16 项测试通过，包含真实无界面 Edge 与本机模拟牌局的协议、回执、超时、取消和重连测试。实机已确认专用 Edge 监听本机端口、游戏页面桥接启用，重复打开和附着保持同一页面及加载时间，启动器返回 `reused=true`。真实账号登录与开局由用户完成；大厅没有本人手牌属于正常状态，不等于浏览器故障。

窗口显示回归实测：先最小化专用窗口，再调用与“打开游戏”按钮相同的入口；结果为窗口已恢复、可见且确实处于前台，原页面加载时间与标签页数量不变。

## 本地选牌与 DeepSeek 解说

2026-10-23 增加独立的本地策略，并在本机配置启用 `worlds.majsoul.localStrategy=true`。人物设定、称呼、聊天风格与共享记忆不变。修改的提示词仅属于雀魂 World，明确模型负责观察和解说。

- 合法自摸、荣和优先；普通弃牌结合普通形、七对子、国士的向听、公开信息下的有效进张、搭子、宝牌与振听。未见牌数不是实际牌山数量。
- 对手立直或三组副露形成威胁时，结合听牌形状、进张和粗略价值决定进攻、兼顾安全或弃和。弃和优先对威胁者的现物；筋和壁只降低评分，不视作绝对安全。
- 吃碰须有役牌、混一色等明确役种基础，且降低向听；不因宝牌多就乱碰。暂不主动大明杠，暗杠、加杠也采用保守条件。三麻拔北保护接近完成的国士与七对子。
- 单一执行器直接调用现有带版本校验、权限检查和服务器回执的桥接。相同操作窗口只尝试一次；失败或结果不明不重发。停止权限会取消尚未发送的等待，已经发出的请求无法撤回。
- 本地模式不注册 `majsoul_act`，旧的缓存调用也会被拒绝。DeepSeek 保留观察、附着和暂停工具，关键已确认动作最多每 30 秒触发一次解说机会；出牌不等待解说或 API。

面板显示“本地策略（DeepSeek 仅解说）”、最近策略理由和回执。配置中的“允许操作当前牌局”控制是否代打；用户说“我来打/停一下”时，模型使用 `majsoul_pause` 暂停，恢复由用户重新开启允许操作。全局暂停事件投递不等同于此项游戏操作权限。

维护源码在 `integrations/majsoul/strategy.ts`、`local-player.ts` 和 `ENV_PROMPT.md`。安装与测试：

```powershell
.\.venv\Scripts\python.exe tools/patch_coopanion_majsoul_strategy.py
.\tools\test_coopanion_majsoul_strategy.ps1
```

安装器要求已应用浏览器修复，检查插件版本，保存 `backups/majsoul-strategy-*` 后原子替换文件，重复应用不产生变更。它不修改用户配置或人设。安装后在局间重启 Coopanion，在雀魂配置中开启“本地代码选牌”，重启使工具列表更新，再附着已有游戏页。不要在进行中的牌局重启。未显式设置该配置的部署保持旧模式，方便回退。

验证包含 30 项测试：原有状态、协议和浏览器回归，以及新增策略、80 手固定随机种子的合法性检查、重复窗口防护、暂停与恢复、模型工具隔离。独立无界面 Edge 对本机模拟服务器确认了无模型出牌、权威动作与回执、暂停后不发牌、恢复后继续操作。测试不使用真实账号或自动匹配。

决策理由和候选评分保存到 `<bot dataDir>/majsoul/decisions.jsonl`，超过 5 MB 保留一份轮转；原始动作回执仍在 `actions.jsonl`。这是可解释的基础启发式策略，尚未加入完整点数期望、排名策略、复杂读牌或多步搜索，也没有用真实对局统计证明胜率提升。

## 陪我玩

2026-10-24 增加“陪我玩”模式。更新插件后，在局间重启一次 Coopanion，然后进入“雀魂麻将 → 游戏状态”，点击“陪我玩”。网页模式使用“打开游戏”显示专用 Edge 窗口，或“附着桥接”连接已打开的专用游戏页面，自己登录、开局和打牌。独立客户端使用下文的“客户端陪玩”。

界面资源会立即更新，后台代码则需要重启进程才能加载，单独刷新页面或重启 World 不能替代进程重启。面板检测到旧后台时会禁用陪玩按钮并显示“重启后可陪玩”，避免发送旧后台不认识的命令；若曾看到“未知游戏管理操作”，从大肥鱼托盘菜单重启后刷新页面即可。

- `companionMode=true` 优先于本地策略和允许操作的配置，同时阻止本地执行器、模型动作工具（包括旧缓存调用）以及底层动作发送。切换时会取消尚未发送的等待，已发送给服务器的动作不能撤回。
- 面板的“陪我玩”和“退出陪玩（保持暂停）”按钮都会关闭 `allowActions`，退出不会突然恢复代打。若直接修改配置中的“陪我玩”复选框，则保留原 `allowActions` 值；要恢复代打，先关闭陪玩并显式检查操作权限。
- 使用现有本地策略计算建议，不执行。面板显示当前建议和理由；你手动出牌、状态不完整或断线后清除旧建议。队列中的解说在投递时读取最新状态。
- `majsoul.advice` 主动唤起原有角色聊天和给建议，普通机会默认每 10 秒至多一次，配置“陪玩建议间隔（秒）”可调为 5–60 秒；新威胁、和牌机会和结算的最短间隔为 3 秒。同一局面不重复触发，没有新机会时不空聊。模型和语音服务仍决定最终回复速度，无法保证在倒计时结束前说完；面板建议不等待模型。
- 保留原有角色设定和语音通道，只新增雀魂环境提示。陪玩期间可以只读重连；不会自动登录、匹配、点击牌或确认结算。

维护代码为 `integrations/majsoul/companion-advisor.ts` 和 `tools/patch_coopanion_majsoul_companion.py`，已并入原策略安装器，沿用上述安装和测试命令。安装器备份后更新插件，不更改当前用户配置、不重启运行中的应用。

验证：38 项策略、状态、渲染和真实无界面 Edge 协议测试通过。其中覆盖本地/模型两种配置下陪玩零动作提交、切换时取消发送前等待、人工出牌后更新建议、退出保持暂停、建议节流及延迟投递消除旧建议。测试使用本机模拟牌局；未使用真实账号，也未验收真实语音播放。

### 雀魂独立客户端

用户明确授权“只截取雀魂客户端窗口发给 DeepSeek，不操作游戏”后，增加了 `companionSource=native`。点击“客户端陪玩（截图发 DeepSeek）”即可启用；退出陪玩立即取消在途截图并使排队图片失效。原“陪我玩”按钮沿用最近选择的画面来源，“切回网页陪玩”恢复网页观察。

- 使用 Windows `PrintWindow` 读取标题匹配“雀魂 / Mahjong Soul”且进程名称属于雀魂客户端的窗口区域，包括 Steam 版 `Jantama_MahjongSoul.exe`；不会选择浏览器、聊天软件或大肥鱼自身。不截图桌面，不使用鼠标键盘，不激活或恢复窗口。唯一窗口自动选择，多窗口时提示句柄供配置选择。
- 使用现有 DeepSeek 连接看图，捕获前和投递前核对当前配置的地址必须是 `https://api.deepseek.com`，同时检查模型支持 JPEG。其他目的地或不支持图片的模型停止截图并报告原因。
- 默认每 10 秒检查一次，客户端最短 8 秒；相同图片不重复投递、过期超过 25 秒的图片丢弃，不会积压旧牌面逐张播报。模型通过原有 `pet_say` 和语音通道说话；速度取决于模型和语音服务，不承诺能在出牌倒计时前完成建议。
- 面板显示窗口名称、观察状态、最近观察时间和已投递画面数。最小化、黑屏、关闭或窗口身份变化时停止有效画面投递并说明原因；不会以桌面截图作为替代。
- 客户端模式不读取网页牌局；无协议级精确手牌、计时或操作列表，建议依赖截图识别，看不清时应直接说明。客户端来源下，即使另行打开 `allowActions`，插件仍禁止游戏动作。

维护源码为 `native-capture.ps1`、`native-companion.ts`，安装变更由 `tools/patch_coopanion_majsoul_native.py` 合入原策略安装器。新增 7 项回归测试，总计 45 项通过，覆盖取消、单次采样、图片去重/过期、目的地限制、看图能力检查、错误恢复和禁止操作。实机验证已能只读捕获标题为“雀魂麻將”的独立客户端窗口。

实机链路已确认：`majsoul.native` 携带窗口图片进入模型上下文，DeepSeek 随后调用 `pet_say` 给出陪玩建议，Fatfish 日志记录 `fatfish speaking`，连续多次观察与发言正常，`allowActions=false`。未修改系统音量或音频输出设备；实际听感仍取决于用户设备。

### 陪玩面板（当前 UI）

入口更新为“雀魂麻将 → 陪我玩”，取代上文的“游戏状态”旧面板。先选择“雀魂客户端”或“雀魂网页版”，再点击“开始陪我玩”；选择卡片本身只改变待选来源，不启动截图或切换连接。“结束陪玩”停止观察并保持游戏操作关闭。网页连接按钮只在选择网页版时显示，先启用该来源后才能连接。

面板集中显示识别到的窗口、观察状态、最近观察时间，以及桌宠最近的实际发言和朗读开关状态。“打开语音设置”可进入原有语音配置；朗读关闭时不会自动开启。“陪玩节奏”支持 10 / 20 / 40 秒预设或自定义间隔，点击“应用设置”立即保存。多窗口句柄和完整状态折叠在“高级与诊断”中。窄窗口下卡片自动改为单列。

维护界面源码为 `integrations/majsoul/webui-client.js`，状态汇总与安装补丁为 `tools/patch_coopanion_majsoul_ui.py`。原策略安装器同时生成带内容哈希的界面文件并更新插件入口，避免一年期浏览器缓存继续显示旧 UI；插件上游版本号保持不变，重复安装无变更。

UI 实机验证已完成：设置 20 秒并保存、恢复 10 秒、启动客户端观察、结束后停止观察、切换来源卡片而不触发游戏连接、显示真实桌宠发言与当前朗读状态。验证结束恢复测试前的停止陪玩状态，保留 `allowActions=false`。45 项原有回归测试通过。
